# 🌍 Global Timezone Finder

A simple, fast, and India-first timezone comparison tool built entirely with HTML, CSS, and vanilla JavaScript — no frameworks, no backend, no external APIs.

## 🔎 What It Does
Global Timezone Finder displays India's current time by default and allows users to instantly search for any country to view its live local time and the exact time difference from India. Perfect for remote teams, travelers, students, and anyone coordinating across time zones.

## ✨ Features
- 🇮🇳 Live India Standard Time (IST) clock by default
- 🔍 Search across 150+ countries
- 🎯 Fuzzy search — handles typos and misspellings
- 💡 Autocomplete suggestions while typing
- ⏱️ Real-time time difference calculator
- 📱 Fully responsive design (mobile & desktop)
- ⚡ Powered by the browser's native `Intl` API — no external dependencies
